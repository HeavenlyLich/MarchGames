# MarchGames
Колекція з 15 інтерактивних освітніх ігор для дітей, розроблена на чистому JavaScript, HTML5 та CSS3. Проєкт має модульну архітектуру, що дозволяє легко додавати нові ігрові сценарії.

## 🚀 Особливості проєкту
- **Модульність**: Кожна гра ізольована у власній папці зі своїми стилями та логікою.
- **Спільні ресурси**: Централізоване керування звуками (Audio Manager) та ефектами перемоги (Victory Logic).
- **Адаптивність**: Використання сучасних методів верстки (Flexbox, Grid) для стабільного відображення.
- **Навчальний контент**: Ігри спрямовані на розвиток дрібної моторики, вивчення кольорів, форм, пір року та англійської лексики.

## Як запустити проєкт локально

Оскільки проєкт не використовує сторонніх фреймворків, запуск виконується максимально просто:

1. **Клонуйте репозиторій** або завантажте його як ZIP-архів:
2. **Перейдіть у кореневу папку проєкту**.
2. **Знайдіть файл `index.html`**.
3. **Відкрийте його у будь-якому сучасному браузері** (Chrome, Firefox, Edge тощо).
4. **Грайте!** Використовуйте головне меню для переходу між усіма 15 іграми.

> **💡 Порада для розробників:** Для стабільного завантаження звуків та асетів рекомендується використовувати розширення **Live Server** у VS Code.

## 📁 Структура папок
- `/assets/` — спільні зображення-маски та звукові ефекти.
- `/games/` — папки з індивідуальними модулями ігор (game1–game15).
- `common.css` — спільні стилі та підключення шрифтів (Comfortaa).
- `audio-manager.js` — глобальний клас для відтворення звуків.
- `victory.js` — логіка завершення гри та конфетті-ефекти.

## 🎮 Перелік ігор
1. **Magic Box Sorter** — Базова гра на сортування об'єктів. Дитина розподіляє кольорові фігури (Square, Circle, Triangle) за відповідними контейнерами, розвиваючи навички класифікації.
2. **Spring Ring Pyramid** — Логічна задача на впорядкування розмірів. Потрібно зібрати пірамідку з кілець (Circle), стилізованих під квіти, від найбільшого до найменшого.
3. **Four Seasons Painter** — Інтерактивна розмальовка, де одна локація змінює свій вигляд залежно від обраного сезону, демонструючи візуальні трансформації природи.
4. **Shape Clouds** — Гра на аудіальну та візуальну увагу. На небі з'являються хмаринки у формі геометричних фігур, і дитина має знайти конкретну форму за текстовою або звуковою підказкою.
5. **Geometric Birdhouse** — Будівництво шпаківні з геометричних фігур.
6. **Puddle Shapes** — Сортування каченят за формою калюж.
7. **Season Wheel** — Вивчення пір року за допомогою інтерактивного колеса.
8. **Dress for the Weather** — Підбір одягу відповідно до погодних умов.
9. **Sun vs Cloud** — Механіка очищення неба від хмаринок.
10. **Singing Bird** — Музична гра на пам'ять ("Simon Says") з англійськими словами.
11. **Windy Leaves** — Сортування листя за відтінками зеленого.
12. **Grow a Flower** — Покроковий симулятор вирощування квітки (State Machine).
13. **Stream** — Аркадна гра з човником та уникненням перешкод.
14. **Bird's Nest Builder** — Збирання матеріалів для будівництва гнізда.
15. **Season Memory** — Класична гра на пошук пар з 3D-анімацією карток.

## 🛠 Технологічний стек
- HTML5 / CSS3 (Custom Properties, Flexbox, CSS Grid)
- JavaScript (Vanilla JS, Async/Await для ігрових послідовностей)
- Canvas Confetti API для візуальних ефектів
